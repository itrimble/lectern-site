API keys & BYOK

Lectern uses your own LLM API keys (stored in the macOS Keychain). Configure providers in the app. Remnant Security never sees your keys or slide content.

Free vs Pro

Free includes 3 generations. Pro is $4.99/mo or $29.99/yr via Apple. Manage subscriptions in System Settings → Apple ID → Subscriptions.

Privacy

Sandboxed Mac app with no telemetry. App Store privacy: Data Not Collected. See the privacy policy for details on BYOK and third-party LLM providers.

FAQ pointers

More answers live on the landing FAQ and in-app at Settings → About. Requirements: macOS 14+, Apple Silicon native (Intel via Rosetta).
